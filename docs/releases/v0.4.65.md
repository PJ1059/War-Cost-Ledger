# 0.4.65 — Combat feedback, career records and English localization

This release brings the local 0.4.45–0.4.65 work into the public release line.

## Highlights

- Automatic English settings, combat notices and career views for non-Chinese game languages; Chinese game languages retain Chinese. Search accepts supported Chinese and English catalog names.
- Live hit/penetration feedback, individual heavy/giant ribbons, reviewed medals and an armored melee ribbon. Includes the 100 vehicle body-impact kills per-mission achievement.
- Expanded kill/death-source resolution, including typed damage catalogs, hellpods, parent weapon payloads, sustained effects and a five-second continuous damage chain. Ambiguous events can still remain unknown.
- Career history with expandable mission/weapon/enemy/death details, time filters, revised K/D charts and a collapsed mission bill at the bottom of each mission.
- Optional ammunition, grenade, support-weapon, stim, heat-sink and maintenance billing, with period totals. Costs are fictional and conversion uses a fixed historical rate snapshot.
- Bounded diagnostic logging and archive/query work for larger histories.

## Install or update

Exit the game. Import `HD2-War-Cost-Ledger-0.4.65.zip` into Arsenal, enable one version and keep Bingus Shared Loader last. Install HD2Runtime, Mod Options Menu, HD2 HUD+ and Shared Loader separately; versions and links are in the [README](../../README.md).

Existing local records are preserved. Back up your ledger before manual changes. The package does not include a player account, gameplay log, external dependency or complete reference mod.

## Verification and limits

The public source is independently built from a sanitized export, with package-content scanning and offline checks. These checks do not prove perfect in-game attribution or exhaustive weapon/multiplayer/language coverage. Game or dependency updates can invalidate native layouts. Build inputs and externally required research checks are documented in [BUILDING](../BUILDING.md).

The video thumbnail keeps its added title and combat-feedback inset above the bottom 20% overlay area. The Nexus main cover is the approved English combat cover; gameplay pixels retain the language of the original recording.
