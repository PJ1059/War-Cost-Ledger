# 0.4.66 — 空投仓与地火来源 / Hellpod and ground-fire attribution

孢子强袭虫等自爆单位：同一目标已经观察到初始／增援／装备空投仓来源、但血量还没更新时，保留最多0.75秒的空投仓证据。随后自爆不再覆盖该来源。不建立普通武器伤害链，不因重复轮询续期。提示、生涯武器统计、敌人关联与原生自爆来源校正一致，不新增费用或碾压奖励。没有任何同目标空投仓线索的瞬时死亡，仍不能凭空恢复仓身份。

地火处理从单个G-8扩展为9个来源、11条精确爆炸事件：G-8、G-10、G-13、G-142、G/40-K、EAT-700的主弹／子弹药、轨道凝固汽油弹的两种炮弹、飞鹰凝固汽油弹和MD-I4燃烧地雷。每种使用自己的静态来源、爆炸外半径和有界关联窗口；MD-I4的共享射弹额外要求事件原生source/owner属于核验的两个资源之一，不允许只凭事件名补源。

只有已观察到的本人爆炸、目标真实位置、死亡时可信的原生火焰元素（life2/kind2/element1），以及本人credit或原有本人击杀额度共同成立，才补区域来源。明确其他武器／敌人／队友来源优先；非火焰、越界、过期、缺少位置不套用。活体Health元素没有可靠更新保证，不能用于创建火源链。原有同目标5秒实际扣血链保持。

G-8/G-10/G-13/G-142分别使用27/20/15/6秒的社区地火池报告作为推断窗口；它们不是实测原生寿命。其余7条事件只使用明确的5秒关联规则，不把它称作燃烧寿命。半径取各自原生爆炸外半径，是关联上限，未证明真实地形覆盖。原生受害者燃烧3秒与地火寿命无关。各项出处、规则、完整静态库存及未启用项见[地火来源目录](../ground-fire-contexts-0.4.66.json)。

已核对28条爆炸、4条射弹及22条组件的非零FireTemplate。喷火器、喷火无人机、火焰哨戒炮、载具喷火等虽可辨别静态能力，当前接口仍缺少地火落点／创建者，不能保证晚到目标全部归属；不在开火者或受害者位置猜造火区。模板5为枚举Count、敌方／环境和不具备闭合来源的分支不自动补为玩家武器。历史记录不回填。

本版验证为离线原生字节回放、真实游戏LuaJIT执行、构建和保护安装检查；实机多人识别率尚未验收。

## English release notes

Preserve short-lived, target-bound hellpod evidence before a dying unit overwrites its source with a self explosion. The 0.75-second window does not renew when the same metadata is polled. It covers deployment, reinforcement and equipment pods without adding kills, fees or vehicle-crush awards.

Extend local ground-fire attribution to nine source families across eleven exact explosion events: G-8, G-10, G-13, G-142, G/40-K, EAT-700 main/bomblet impacts, both Orbital Napalm shell branches, Eagle Napalm and MD-I4 Incendiary Mines. Each uses its own typed identity, native outer explosion radius and bounded association window. The shared MD-I4 family additionally requires one of its reviewed native event source/owner hashes.

Area inference requires an observed local event, target position, verified fatal fire element and local creditor or the existing native local-kill quota. Known weapon/foreign sources remain authoritative. Stale live Health-element bytes cannot seed a fire chain. Existing five-second target damage chains and original saved data are preserved.

The four grenade windows (27/20/15/6 seconds) are sourced community ground-pool reports, not verified native lifetimes. Other enabled events use a conservative five-second association rule. Native explosion radii bound inference rather than proving the exact ground footprint. Spray weapons, flame sentries/drones/vehicles and code-created fire still lack a verified creation position/instigator path and are documented gaps. Offline replay coverage does not replace live-game verification.

Uses code/research from [HD2Runtime by SkyeShade](https://github.com/SkyeShade/HD2Runtime) and typed settings from [Filediver by xypwn](https://github.com/xypwn/filediver). Individual duration reports and pinned input hashes are recorded in the ground-fire catalogue.
