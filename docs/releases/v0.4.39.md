# 0.4.39 · 生涯战果档案与滚轮隔离（测试版）

已上传完整源码、测试、审核素材与价格工作簿。此版本仍有未接入功能，请先阅读 [当前状态](https://github.com/PJ1059/War-Cost-Ledger/blob/main/CURRENT-STATUS.md) 和 [局限清单](https://github.com/PJ1059/War-Cost-Ledger/blob/main/LIMITATIONS.md)。

## 已确认

- 生涯档案的累计／历史按钮、卡片展开与收起、图案悬停条件、字体及灰白配色已通过玩家实机确认。
- 鼠标在档案内时仅滚动档案，移到左侧恢复原生生涯列表滚动；上下按钮和删除历史功能已移除。
- 重型／巨型本人击杀已接入已映射类型，分别计入“反重”和“巨人杀手”；部分四类子弹命中有实战确认，其中实际跳弹图标已确认。
- 保留中途返舰历史、全部／24h／7d／30d汇总及独立生涯 KD 比较。标准治疗针已接线为 2,500 MC／支，实机使用扣费待单独验收。

## 尚未接入与局限

- 侦察绶带、普通虫洞封口／虫巢拆除绶带、毒气手雷等未证明的投掷物消费、成功点燃／中毒状态施加尚未接通完整正式来源。
- 主支线完成／协助、爆头、距离击杀、补给／治疗队友、辅助装弹及依赖这些事件的其余成就仍有缺口。
- 价格目录不等于全量计费覆盖。特殊调用、弹种切换、连续／热量／弧电、部分背包或下挂武器等消费未完整覆盖。
- 重型／巨型分类依赖类型映射与本人死亡归属；未知敌种、快速消失或读取中断会漏记，不保证所有变种。四类命中不覆盖所有攻击方式，也不保证与原生总命中相加相等。
- 历史仅含 MOD 已观察记录，最多 500 场；满额暂停新增，没有删除入口。未知时间和缺少生涯基准保持未知，无法重建启用 MOD 前的战果。
- KD 检查点保留 31 天，缺少目标时点之前一小时内有效基准就不计算差值；“全部”并非完整生涯起点。
- 绑定已核对的游戏构建／依赖版本；尚无全部武器、敌种、多人房主／客机、分辨率和持续 FPS 的完整实机矩阵。Runtime 禁用原生鼠标钩子时，不承诺滚轮隔离。

## 安装与验证

正常退出游戏后，在 Arsenal 导入 `HD2-War-Cost-Ledger-0.4.39.zip`，同一 MOD 仅启用一个版本。依赖单独安装：HD2Runtime 0.30.3、Mod Options Menu v1.2、HD2 HUD+ 0.2.1、Bingus Shared Loader v19；Shared Loader 保持最后。
