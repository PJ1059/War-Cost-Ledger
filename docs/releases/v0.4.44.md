# 0.4.44 · 生涯战斗统计与界面修正（测试版）

本次发布包含自 GitHub 0.4.39 以来的 0.4.40–0.4.44 改动。费用均为 MOD 内的虚拟账单，不扣除真实货币或游戏货币。

## 本版变化

- 生涯档案新增“死因／武器／敌人”，保留“战果／对局”。支持死因排名和近期记录、武器分类、敌人筛选、搜索、分页和单条展开；队友在排名中统一归为“队友”，详情保留可读取的当时身份线索。
- 修复 HUD+ 0.2.4 下档案不显示，分类改为真正的下拉菜单并修正缺字。武器／敌人摘要只显示击杀数与种类数，移除关联率，“其他战备”改称“战备”。
- **0.4.44** 去掉敌人阵营下拉中的“未知敌人”选项和武器细分类菜单，保留主武器、副武器、支援武器、投掷物、战备。只精简界面，未知记录和原始计数仍然保留。
- 命中与扣费提示可各自选择中央／右侧／不显示；绶带保持右侧，并依据原生拾取提示占用调整位置。瞬时提示图标和文字放大 50%，右上三枚统计图标缩小并与骷髅头居中。以上战斗显示变化的实机表现仍待验收。
- 已接入 22 类投掷物库存下降计费、活体目标命中过滤、新战斗明细保存。代码接入与离线检查已完成，实战准确性仍有下述边界。

## 当前局限

- **武器与敌人尚不能逐次配对。** 两类击杀分别统计；不知道具体敌人由哪把武器击杀时保持未知。旧对局缺失的死因、武器和敌人明细无法补回，新采集也可能因未观察到或读取失败而缺失。
- **死因是来源线索。** 最近伤害归属不保证等于最终致死来源；致死武器、伤害类型和恶意 TK 意图无法确认。能保存队友当时昵称、槽位及会话 peer，但尚未取得 SteamID64／PSN／永久游戏账号；会话 peer 不能当作永久身份。
- **战斗修复未全部实机验收。** 包括毒气手雷等投掷扣费、攻击尸体过滤、提示位置与治疗针扣费。毒气手雷配置为 180 MC／枚，标准治疗针 2,500 MC／支；同一采样间隔内补给可能抵消库存下降。重型／巨型／飞行绶带只覆盖已映射且能观察本人最终击杀归属的类型，可能漏记。
- **历史与 KD 有记录范围。** 原对局卡片最多 500 场，满额暂停新增；新战斗明细独立保存。意外退出可能丢失最后约 5 秒批次。缺时间的旧记录只进“全部”；24 小时／7 天／30 天的生涯 KD 比较缺少真实基准时显示未知，“全部”也不代表完整生涯起点。
- **兼容范围有限。** 仅针对已核对的 Windows x64 游戏构建与依赖组合；未完成长期多人、高负载及所有分辨率组合验证。中文搜索通过聚焦后 Ctrl+V 粘贴，尚无完整输入法候选窗口。与其他使用全局鼠标捕获的 MOD 并用仍有待验证。

## 尚未接通的功能

- 侦察发现者归属与侦察绶带、普通虫洞／虫巢关闭者归属与拆除绶带。
- 撤离保障扣费、飞刀回收，以及增援、求援、地狱火炸弹、SEAF、飞鹰重新装填等部分特殊调用计费。
- 成功点燃／中毒的施加者与生效周期、主线／支线完成及协助归属。
- 爆头、连杀、距离击杀、补给／治疗队友、辅助装弹等完整事件，以及依赖这些来源的成就。
- 可切换弹种、热量／弧电／连续燃料、背包和下挂武器等部分特殊消费。价格表、图案或研究样本存在不表示功能已接通。

## 安装与文件

正常退出游戏，在 Arsenal 导入 **HD2-War-Cost-Ledger-0.4.44.zip**，同一 MOD 只启用一个版本。依赖单独安装：HD2Runtime 0.30.3、Mod Options Menu v1.2、HD2 HUD+ 0.2.1／0.2.4、Bingus Shared Loader v19；Shared Loader 保持最后加载。游戏内设置位于 `ESC → MODS → 战果与战争账单`，生涯档案位于 `军械库 → 生涯`。
