# 0.4.68 — Runtime and HUD+ compatibility

- Replace the exact HD2Runtime 0.30.3 lock with API 1 and required-capability checks. Report specific missing modules or methods. Examined official versions: 0.30.3, 0.31.3, 0.40.0 and 0.40.1.
- Support HUD+ 0.2.9's modern lifecycle contract with actual Runtime combat rendering. Preserve native rendering on legacy 0.2.1 / 0.2.4. The Runtime fallback does not require a HUD+ host; no native lifecycle adaptation is claimed for 0.2.8.
- Add a ship Career window: **F9** opens it; **F9 / Escape** closes it. Reuse existing tabs, filters, search, history, records and award double-click jumps. Mission F9 collection behavior stays the same.
- Preserve saved history, statistics, attribution and original monetary values. No dependency downgrade or historical backfill.

Known settings/menu and focus signals release archive ownership. Runtime has no general native-menu API. Input blocking can fail with its optional hook-off installation; availability is reported rather than assumed.

Offline regression does not establish live pixels or input behavior. See [current status](../../CURRENT-STATUS.md) and [dependency details](../dependency-compatibility-0.4.68.md).
