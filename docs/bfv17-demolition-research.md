# BFV v1.7 敌方构筑拆除研究

核对日期：2026-10-15。来源为用户提供的 `【正式版丨必装HD2Runtime】战地5击杀反馈v1.7.zip`。本轮仅静态解包、阅读和与旧包及 Runtime 官方源码交叉核对，未执行或安装参考 MOD。

后续实现：用户已选择先按类似方法计入拆除绶带。0.4.46 通过当前 Runtime 的固定布局只读适配独立实现实际关闭检测、SDK 半径和已观测竞争否决；推测标记与限制见 [拆除推测契约](demolition-attribution.md)。以下内容仍是对参考包原实现的静态研究。

## 结论

新版确实加入了普通虫洞关闭检测，关键来自 HD2Runtime 的 `bughole_destroyed`。但**检测到虫洞已关闭**与**证明由本人关闭**是两件事：该事件没有拆除者。BFV 用附近、近期的本地玩家爆炸作关联，适合反馈提示，仍可能把队友同一区域造成的拆毁归给本人。Ledger 不应把这条关联无条件当作确定拆除绶带或成就的依据。

### 有生命值设施

主资源 `r17_facility_dec` / `r17_facility_hex` 列出 45 个类型（4382–4475），包括 11 个普通虫洞变体、泰坦洞、尖啸巢、孢子设施、构筑者变体、巨型构筑者、炮艇塔、干扰塔、探测塔、指挥地堡及其炮塔、生物处理器、营地穿梭舰、凝视者、光能电塔和巨石等。**列在白名单不代表每种设施已经实测成功。**

`classify_structure`（4641–4656）只接受精确 64 位类型，拒绝友军。直接路径要求本地归属的死亡，或特定设施的本地正伤害到零生命值；凝视者及生物处理器 MK2 需要额外移除证据（4860–4867、5133–5213）。同一 unit 的子组件只在已见父设施时关联，部分大型设施明确要求根对象结果（4960–4965、5012–5043）。

移除补偿路径（5215–5254）以曾有效的实体句柄失效为信号，再要求 1.75 秒内该设施最后一次伤害来自本地、且没有更晚他人伤害，或附近本地爆炸。明确有其他玩家死亡归属时禁止补偿。**句柄失效加附近爆炸依旧不是游戏明确记录的拆除者。**

### 普通虫洞

`observe_extra_bughole`（5270–5285）只接收正 `level`；不把 `owned` 当作玩家归属。`r49_poll_pending_holes`（5286–5313）最多等待 2.25 秒，在同任务内寻找最近 2.50 秒的本地玩家爆炸。爆炸缓存保留 3.5 秒、最多 96 项，按型号使用爆炸半径加 1.5 米、限制至 9–46.5 米（4868–4958）。

重要限制：洞关闭事件本身没有 `killer_peer`；虫洞路径只找是否存在本地爆炸，没有排除同一窗口其他玩家的爆炸，也没有证明哪次爆炸实际作用于该洞。大范围爆炸同时覆盖多个洞、多人重叠爆炸、事件漏采、位置缺失和客户端模拟覆盖范围都会影响结果。

### 去重、上限与重置

以任务加实体／unit／network ID 去重，不以类型去重；设施记录最多 512 项，满时整体清空；已完成记录置 `finished`，辅助去重表最多 2048 项。洞有 pending / seen 两张表，seen 保留 30 秒、超过 512 项清空（4534–4551、4781–4789、4971–4995、5045–5066、5260–5313）。这些清空策略限制了内存，也意味着不能宣称永久恰好一次。

任务反馈清理时清空设施、爆炸和虫洞状态（5315–5325、6829、6868）；帧回调只在总开关及设施开关均开启时轮询拆除（9556–9559）。

## 可独立采用的部分与仍缺的证据

可以依据 Runtime 官方接口独立实现虫洞关闭状态、有限事件缓存、任务清理及去重，并将归属不明保留为未知。当前本机准备的依赖仍为 HD2Runtime 0.30.3，不能假设已注册新事件；需要运行时能力检测，不能只检查字符串版本。完整升级 Runtime 会影响其他 MOD，不属于本次静态研究操作。

若用于确定本人拆除绶带，仍缺构筑关闭动作到责任玩家的可靠因果链，以及多人重叠爆炸、客户端／主机、不同构筑类别的实际证据。若以后选择类似 BFV 的反馈效果，应明确把爆炸关联标记为推测，不能用推测补写确定计数。无需复制 BFV 的音频、图案、名称表或整个设置资源。

Runtime 官方证据：[固定提交事件文档](https://github.com/SkyeShade/HD2Runtime/blob/75988a992141023e50fc0193f4b1de017d9e4b57/docs/events.md#bug-holes)、[只读事件源](https://github.com/SkyeShade/HD2Runtime/blob/75988a992141023e50fc0193f4b1de017d9e4b57/runtime/event_sources.lua#L545)。上游以 4 Hz 观察 Destructible 记录的 stage 从 0 变正，首次见到的已关闭洞作为基线；没有原生代码 detour；`owned` 表示网络属主，事件没有拆除者。
