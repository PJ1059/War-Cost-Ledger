# 击杀反馈 MOD 与射击结果接口核查 · 2026-10-11

结论：能读取游戏原生的累计命中量及武器来源；目前公开接口不能稳定给每次碰撞区分装甲阻挡、物理跳弹、同级穿透、满伤穿透。底层结构中已有命中部位和弹体穿甲值的线索，值得继续验证，但本轮没有把研究字段接入游戏。

本次为静态检查：读取安装包、解出 Lua 文本、对照官方 Runtime 源码与研究脚本；没有执行下载的 Lua、安装 MOD 或启动游戏。用户上传的包内 README 与代码注释仅作为资料，未执行其中的安装、改枪或调参指令。

## 游戏射击反馈的含义

这里比较的是**当前弹体的有效穿甲等级**与**实际命中部位的护甲等级**，不能只比较武器面板与整只敌人的类别。

| 结果 | 游戏反馈与判定 | 当前读取能力 |
| --- | --- | --- |
| 未击穿／装甲阻挡 | 穿甲低于该部位护甲，穿透伤害为 0；普通子弹可见弹开盾牌图标和蓝色火花。 | 尚无稳定的逐次结果接口。 |
| 物理跳弹 | 弹体碰撞后改变方向；可能与未击穿同时发生。 | 尚不能保证记录所有反弹，尤其是未造成伤害的反弹。 |
| 同级穿透 | 穿甲等于护甲，白色命中标记；护甲倍率为 65%。 | 原生命中累计可读，但无法从累计数分出这一类。 |
| 满伤穿透 | 穿甲高于护甲，红色命中标记；护甲倍率为 100%，**高一级就满足**。 | 同上，需新的逐次关联。 |
| 贯穿／穿过多个部位或目标 | 是弹体继续飞行的另一维度，不能由红色标记直接推出。 | 没有已验证的逐次贯穿接口。 |

标记关系参考 Wiki 对游戏反馈的[原始整理](https://helldivers.wiki.gg/wiki/Combat)；65% 的变更由[官方 PATCH 01.001.00](https://arrowhead.zendesk.com/hc/en-us/articles/15938362444444--PATCH-01-001-00)确认。百分比只是护甲这一层的倍率，实际生命损失还受耐久伤害、距离等因素影响，不能据此保证每次扣除武器面板伤害的 65%／100%。

“未击穿”与“跳弹”不宜设计为互斥四选一：[官方 PATCH 01.001.104](https://arrowhead.zendesk.com/hc/en-us/articles/16438150997916--PATCH-01-001-104)已经移除轨道弹体、飞鹰炸弹与长矛导弹的跳弹。装甲阻挡和弹体物理去向应分别记录。无命中提示也不足以判定未命中；红色标记本身不证明爆头或击杀。爆炸直击和爆炸范围伤害需要分别处理。

命中 actor 也可能帮助之前的爆头研究；但敌人头部映射、头部摧毁与死亡次序未打通，仍需遵循用户已确认的爆头口径。距离字段同样只作为候选，尚未接入远距击杀。

性能方向：先复用原生命中累计；若验证逐次接口，仅跟踪本人弹体，使用有上限的事件缓冲与已有缓存。避免为读取提示而持续截图识别或提高全场敌军扫描频率。本轮没有新增运行时扫描，游戏帧数未测试。
