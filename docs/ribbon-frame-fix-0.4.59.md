# 0.4.59 绶带边框修复

用户实战截图显示吐酸泰坦“巨人杀手”仅有中央图案和计数，横向边框缺失。战斗HUD的数据与布局已输出边框位置，但创建原生控件时仅将R/H旧编号视为绶带，遗漏G/T新编号。6种巨型与18种重型都受影响，且同一分支创建的数字底板也缺失；侧边提示和累计收藏共用此处。

本版将原有绶带控件分支补齐G/T编号，沿用现有边框纹理、坐标、材质和数字底板。成就勋章、准心命中小图标与生涯路径保持原行为，不修改图案或奖励、计费和记录规则。

回归检查使用已有HUD+ 0.2.1与0.2.4真实宿主代码，在隔离的LuaJIT环境验证全部24种新单位绶带的原生边框、数字底板及可见状态，并检查旧绶带、勋章与命中图标。原版失败／修复版通过及完整包检查保存在 `dist/ribbon-frame-0.4.59/`；实际新版本游戏像素不等于离线验证。
