# 自动中英文界面 · 0.4.65

使用锁定版本 HD2Runtime 0.30.3 的 `text_resources.language(world.runtime)` 只读语言接口。cn（简体）和 tc（繁体）显示原中文；其他语言显示英文。尚未读取语言时默认英文，读取暂时失败时保留已知语言。每秒最多一次，沿已有 world 更新调用，不新增 hook 或扫描。

设置、战斗奖励、击杀来源提示、费用提示和生涯界面在显示层翻译，先翻译再截断。MOM 动态文案在重新打开菜单时更新；战斗和生涯展示随语言切换刷新。昵称、呼号、查询输入、内部键、存档、价格和奖励条件保持原值。搜索同时支持原名及英文别名。

英语名称优先复用现有来源、敌人和价格双语目录。字典、动态句规则及同名冲突说明见 localization-en.json；本地离线验证记录见 dist/localization-0.4.65。两版16:9宣传封面使用实际生产模型和已保存记录排版，单独存放，不增加游戏纹理。
