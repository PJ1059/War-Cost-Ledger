# 打开生涯统计页同步

0.4.19 接入玩家主动打开的完整生涯页。在飞船进入军械库 → 个人资料／潜兵 → 查看统计，保持约3秒；关闭页面后使用最近生涯基准，加上同步后由MOD观察的击杀、死亡增量。没有打开完整页时保留已有基准。

ESC → MODS → 战果与战争账单 → **打开生涯页时同步历史KD** 默认开启，按应用可以关闭；选中此设置可见最近同步的两项数字、KD和UTC时间。说明通过Mod Options Menu的公开函数文本接口在ESC菜单打开时刷新。Runtime日志中成功记录“生涯同步成功”。

只在原生Ship=3且非任务时每秒检查一次。两次连续可见观察的本人身份、控件和数字一致后保存。完整读取只取敌方击杀和死亡两行，最多64次／8KiB，2ms软检查点；关闭页面不会再遍历两行，战斗中完全跳过此读取。一次同步I/O无法中途抢占，真实游戏耗时须实测，不能由此宣称零帧数影响。

数据来自实采标签和值：EnemyKills F68F08B2、Deaths32C9CF0D、COUNT模板2BAA24A7、参数AB2A7B35/type4/high32=0。真实页面已核对351849／4633；生产reader仍需一次开页与关页回归。本人peer在读取前后与Runtime本地玩家核对；只接受page_visible，不接受隐藏缓存。两次相同值表明页面显示稳定，不是服务器刷新证明。

成功时只替换career_kd基准，并保存当前combat_history作为增量锚点；勋章、消费、游戏生涯数据保持。读取失败、页面重建或数值变化时不写0，保留上次基准。相同数字与增量锚点不重复保存或刷日志。再打开生涯页会按其实际显示重新校准，避免重复叠加MOD累计。

普通上舰自动同步暂缓。弹丸四类命中仍被原生采点写保护阻断，此功能不依赖该路径。原总命中、发射、消费等继续独立记录。
