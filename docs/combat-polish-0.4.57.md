# 0.4.57 毒气来源、生涯显示与查询

## 毒气与敌方伤害

最新真实第41局消耗4枚G-4毒气榴弹，来源统计没有G-4，毒气绶带为0，但敌人死亡观察仍在工作。此前的错误前提是：毒气也能先提供一枚普通弹体的已知武器命中，再通过连续未知伤害追溯。G-4实际由爆炸施加Gas状态，并不需要经过普通射弹命中；仅修改连续链间隔无法建立缺失起点。

固定SDK中G-4使用Explosion177→DamageInfo449→StatusEffect42（Gas，6秒）。本版按6条审核的精确爆炸事件名、本人归属和真实位置建立毒气上下文：G-4、轨道毒气、毒气迫击炮、S-11、毒气地雷及飞鹰毒气。名字匹配是完整路径，不按名称含gas猜测；真实可识别来源优先，销毁后的投掷物允许精确事件名补母来源。清单与输入SHA见gas-status-contexts-0.4.57.json。

未知目标在本人本次毒气作用范围内实际扣血时，可近似建立对应母来源；轮询、治疗、无扣血接触不建立。6秒来自已证明的状态持续时间，并不代表已还原完整气云生命周期。原有1.5秒连续实际受伤规则继续使用，普通爆炸仍为0.8秒；已证明的其他死亡机制不借过时毒气上下文。缓存仍最多64条，位置仍在每轮原有8次增强与2ms软预算内读取。

明确的敌人来源不再一律过滤成未知：另一已识别敌人作为实际伤害owner时，提示其名字并标注友伤；只有owner就是死者、且当前有效死亡记录为爆炸，才标注自爆。并不把地图上的敌人互杀自动计为本人击杀；本人计数仍来自原生归属或已有原生击杀增长额度。近似判断可能误配，未知字段缺失仍可能保留未知，旧记录不能倒填。
