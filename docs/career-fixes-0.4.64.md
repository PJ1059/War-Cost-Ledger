# 0.4.64 · 生涯显示与死亡自爆归属

单局爱国账单移到武器、敌人与战果之后，默认只显示可点击的标题和金额。点击展开费用，再次点击收起；重开对局或切换时间范围恢复收起。关闭账单功能继续按原设置隐藏入口。

时段 KD 原先要求截点前一小时内存在基准，否则整段曲线都不显示。现在有可用基准时沿用，否则从所选范围内第一条实际记录开始比较，并标记“记录起点”和真实时间。24 小时、7 天与30 天各自筛选，保留真实 KD 数值和时间分布，不补造缺失的历史。

“等级不是问题”继续使用已批准的剪刀剪钢板构图。由原图直接编译并保留边缘透明度，M11 单独使用无损 RGBA8 纹理及缩略级，去掉有损压缩产生的断裂和块状边缘；256×256 纹理与42像素界面布局不变。其他图案和奖励条件保持原样。

武器与敌人关联只显示名称、数量和入口，移除“（推测）”及同类可信度提示。内部归属证据和原始记录保留；未知仍归为未知。

死亡自爆此前被当作一个新的已知来源，覆盖同目标的前序武器。现同一身份、5秒有效伤害链内有本人武器时，自爆保留最近武器；仍保留真实自爆原始来源以校正原生统计，避免重复计杀。孢子强袭虫与同机制孢裂变种适用同一规则，不按当前手持武器猜测。无前序来源、已过期、其他敌人攻击和非本人归属仍沿用原规则。

离线验证覆盖折叠/展开/重开复位、计费开关、时段基准回退、源纹理和两版HUD宿主、同目标武器与自爆边界、密集击杀及保存重载。图形预览使用真实保存记录和生产绘图参数，不等于游戏截图；新版本实战准确率尚未测得。
