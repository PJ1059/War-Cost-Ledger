## 计算与恢复

使用原生XZ平面：父world Z为+9C，world Z比例+8C，本地高度+10。局部任务起点取父padding和前置可见项的原始间距、高度、后间距；不取动画中的当前位置。战果根节点上边缘对齐此起点加本MOD上边距，右边缘依据父宽度450计算。游戏父级缩放、偏移由原生树传播，不从屏幕叠层位置反推。

增加任务前间距 = (上边距 + 实际战果内容高度 + 任务间隔) × 本MOD局部比例 / 首个任务节点本地Y比例。关闭任务让位仍可取得同一父级几何，但不增加间距；F8则停止展示并恢复原值。无已收纳绶带时默认106内容高度，默认18上边距与12任务间隔，局部预留136；地图展开随实际绶带行数增长。

2560×1440真实打开地图样本：父上边缘38.4px，前置可见计时器38与资源48、任务原间距10，任务局部起点96、屏幕起点153.6px。0.4.8旧平面方案按UI屏幕下边缘259.555556px增加88.2963本地单位。0.4.9改为局部内容预留，默认无绶带时增加136本地单位，父比例1.2时下移163.2px；无需平面渲染器先画一帧取得屏幕尺寸。

每次操作重新核对构建SHA、三段精确机器码、固定5记录链和6个控件身份/context/父级/比例。只修改任务或当前目标记录的4B前间距与父layout的1B dirty；原生排版传播任务子树。读写发生在原10Hz更新，不追补长帧；不变化时不写、不调用排版。正常读取2261B，字节限额不构成CPU耗时保证。

HUD+扩展独立Lua资源首行声明HD2_HUD_ADDON，通过公开Core.merge/Reader/Widgets接口注册。它只读取账单模块的缓存native_hud_snapshot，无额外战果或全树扫描。控件使用hud_text_font(2)、variant(1)、layer551；图案使用游戏mask_material和曲面参数。舰上独立预览仍为平面图案预览，战斗中禁止同时画旧叠层。原生父身份失效、手动采样、F8隐藏时缓存清空。

保存当前HUD/context的原始间距和本MOD最后值。原生矩阵float32舍入造成的小于0.01px变化会沿用本MOD上次间距，不重启排版动画；恢复始终使用原始4B，不应用此容差。F8/关闭让位/返回舰上时仅恢复仍由本MOD持有的值；其他MOD改过的字段会让步，且停止本HUD实例的修改。读不到world或身份不匹配时不写旧地址。手动采集前恢复，取样数据与真实战果保持独立。
