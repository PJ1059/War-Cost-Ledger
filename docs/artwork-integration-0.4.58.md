# 0.4.58 图案与单位绶带接入

本版本替换 R05 近战肘击、M08／M09／M10 三枚民主之星、M11 剪刀剪钢板，新增 M12“摧毁暴政减速带”与 G01—G06／T01—T18 共24种单位绶带。原图、旧资产和旧版本包保留；其他图案不修改。

- M08／M09／M10只取用户认可总览的上排三枚大图，不带下排缩略图、罗马数字，不采用后续改脸稿。原图 Library ID `local-generated-source`；SHA256 `54fdae1296542575a580329e5dde3d5f0b748ca0f4e47ca76ec292084d339842`。

- 仅用确定性的裁切、黑底转透明和窄边缘去黑晕，不重新生成或重画。统一1536方画布、保留原前景像素比例。眼窝、鼻孔、炮口和结构缝隙作为透明负空间保留。

## 单位绶带和成就

6种巨型统一名“巨人杀手”，18种重型统一名“反重”，每种使用对应单色图案与计数。新确认的单位只发对应变体，不同时发同一次通用奖励。旧 R02／R03 记录继续展示；未知或未映射的类型可回退，不倒填旧局。

M12规则由用户明确批准：当前同一局本人载具父车体来源击杀累计达到100，获得一次。阵亡不清零，新一局重置；炮与机枪来源、队友来源、旧历史派生均不计入本次判定。三个民主之星、等级不是问题和其他成就的现有名称、阈值与规则不改变。

R05沿用认可的前景肘部透视，增加简化肩甲／肘甲／护手，仍是横向绶带。M11为剪刀剪开厚钢板，获得条件仍是2级或以下穿甲武器击杀重型／巨型单位。

## 构建和验证

沿用现有HD2Runtime图像与纹理管线，源PNG按alpha可见框等比适配256纹理，再转为白R／金G遮罩。53份奖项图案、4份统计图标、2份指标、固定绶带框和生涯底色共123个图标资源，全包再含两份Lua资源，共125项。

`tools/prepare-integrated-icons.py`生成并校验资产映射；`tools/prepare-game-icons.py`转换纹理；`tools/build.py`构建本地0.4.58包。原始来源、Library身份、裁切、输入和输出SHA随包保留。完整离线检查与受保护更新的实际结果以 `dist/combat-fixes-0.4.58/` 为准；未进行新版本的实战画面验收，不对外发布。
