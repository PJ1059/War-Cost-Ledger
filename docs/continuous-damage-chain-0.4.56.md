# 0.4.56 连续伤害链归属

按玩家确认的规则，同一目标连续实际受伤时，沿用这条伤害链内最近一次能识别的武器。未知伤害的编号、owner 或不透明 token 变化不再单独切断归属，替代 0.4.52–0.4.55 的第二未知段截断规则。

## 当前规则

- 相邻两次观察到实际扣血的间隔不超过 1.5 秒，算同一条链；恰好 1.5 秒仍延续。
- 链内出现新的已知武器，后续归属随之替换。其他未知伤害可以连续延续，没有“已知武器超过几秒就失效”的额外上限。
- 超过 1.5 秒没有实际扣血，再出现未知伤害时保持未知。轮询、来源字段变化、治疗、没有主生命值变化的接触均不延长计时。
- 目标实体／descriptor／unit／generation、任务或玩家生命切换，以及读取中断，清掉旧链。新链必须重新取得来源。
- 实际来源资源、唯一伤害编号、已有的附近本人爆炸关联继续提供来源；共享破片编号本身不能直接等于 AC-8。初次看见已死目标时，可使用当次直接可识别来源，但不建立可续用的活体伤害链。

例子：AC-8 命中后，目标每隔 0.5 秒受到不同编号的未知伤害，最终死亡，可归 AC-8。如果停止扣血 2 秒后再被未知伤害杀死，则不沿用此前 AC-8。若中途识别出另一把武器，就归最新的已知武器。

## 输入和限制

目标观察约每 100 毫秒进行一次，每轮最多增强 8 个发生变化的目标，仍受原有读取和 2 毫秒软预算约束。计时来自客户端观察到生命值下降或活体转死亡的时刻，不是游戏原始逐击时间戳。原生命中队列每轮最多取 64 条，没有新增逐击时钟或全地图扫描。

因此，同一个观察间隔内的多个命中可能合并；预算、队列积压和网络更新会影响观察时间。完整逐次持续伤害编号尚未取得。若未知的另一把武器在 1.5 秒内接手并持续造成伤害，仍可能被归入原已知武器，这是本次采用宽松归属的明确取舍。仅有护甲／部位伤害而主生命值未变化，不为这条链续期。

已有来源归并、生涯保存、绶带和成就沿用原路径；最终 raw 来源缺失的已继承击杀另存 `_unknown` 校正额度（不是武器哈希），仅在同局来源合计超过实际击杀时扣除未知显示池，保留原始数量并支持重载去重。显示击杀来源开关仍只控制提示。旧记录缺少逐击时序，不能按新规则倒填。本轮不改原生命中机器码、静态哈希目录、账单价格或计费规则。
