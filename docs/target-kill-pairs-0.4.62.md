# 逐目标击杀关联

此前生涯仅保存武器和敌人各自的总数，展开关联列表时统一填为“未知”。0.4.62 为之后实际观察到的目标伤害来源增加汇总关联。

运行状态及每局存档使用同一可选字段：

```lua
kill_pairs = {
    ["敌人资源的16位大写十六进制哈希"] = {
        ["武器资源的16位大写十六进制哈希"] = 累计次数,
    },
}
```

- 只接收同一目标已解算出来源的击杀。没有目标联系的原生来源总数、时间接近或当时手持武器不能产生关联。
- 每对仅保存累计次数，重复快照取较高值；不新增逐杀日志。原始敌人、武器和原生击杀总数保持原有存储方式。
- 查询先按目录将资源哈希合并到武器及敌人名称，再按每局校正后的武器数量、敌人数量和原生击杀总数限制可展示关联数。超出部分不改写存档。
- 武器页面展示它击杀过的敌人；敌人页面展示击杀它的武器。已有关联标注“推测”，剩余数量合并为最下方的“未知”。
- 缺少该字段的旧对局继续保留未知关联，不用其他对局的证据回填。

查询返回 `totals.linked_kills`、`coverage.inferred_pairs`；关联存在时 `coverage.linkage` 为 `target_bound_inferred`。每条已知关联含 `inferred=true`、`confidence='inferred'`。`coverage.per_victim_weapon=false` 保留原生逐杀配对尚未取得的事实。

验证：`tests/test_combat_pairs_062.lua` 覆盖存取、重复快照、原始计数保留、双向别名、校正后限额、过滤范围及旧局不回填；`tests/test_career_combat_panel.lua` 覆盖推测标识与未知余量。
