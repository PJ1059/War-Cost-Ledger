# 0.4.12 命中绶带与接口接入尝试

总命中已接入原生任务父 HUD：打开地图（或设置为常驻收纳）显示 H01「命中」绶带和累计数字。H01 不充当尚未取得分类的即时小图标。射击费用、FIRE 火焰击杀和点燃是独立记录。

## 当前接通范围

- 本人的原生 `projectiles_hit`（`0x897A5551`），共用现有每秒10次的单一来源块读取，没有新增敌人扫描或事件轮询。当前 SDK 映射91个个人弹丸武器来源；未归属、未知、载具／纯战备来源不加入此累计。
- SDK 确认有 Projectile 分支的主、副、支援武器及下挂。喷火喷流、光束、弧电和持续异常不以伤害量换算为命中。保留燃烧破裂者与 Stoker 主枪普通子弹；Stoker 喷火下挂、火炬手、打火机、FLAM-40 排除。
- 首次读到显示当前原生累计，重复快照不重复计数。来源表缺失或换位不能凭来源增长超过原生总增长；换位冲突重新建立基线。原生表归零／本地玩家实体变更时保留本局已累计数但断开旧基线；新任务清零。F8隐藏继续统计，账目包含 hits／hit_sources／hit_stats_ready。
- 合成边界与实际构建入口、现有原生 HUD+ 创建链通过离线回归。游戏内像素和 FPS 尚未实测。原生总统计不含逐次目标，不能据此宣称仅命中敌人；也不能统计命中敌人数、爆头、装甲等级或穿透人数。

## 自动采集

外部工具与 Codex 无关，可关闭 Codex 后正常开游戏。聊天、状态、命中工具按顺序执行，各等正常启动／模块就绪，成功缓存即停止；没有120秒待机退出。它们只取小范围代码，不采全场单位，不要求动作前后采样。各自的成功仅证明材料取得，不能代表功能计数已接通。

源与验证见 `dist/hit-stat-sources.json`、`dist/verification.json`、`dist/test-0.4.12.log`、`docs/recon-chat-integration.md` 和 `docs/native-status-reader-research.md`。本版本未实机确认前请以这些验证边界判断覆盖。
