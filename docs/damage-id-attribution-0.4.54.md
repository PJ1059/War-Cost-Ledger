# 0.4.54 真实伤害编号与派生来源归属

版本说明：原生编号与静态派生关系继续使用；本文的第二未知段截断已由 0.4.56 的 [1.5 秒连续实际伤害链](continuous-damage-chain-0.4.56.md) 取代。

本版将具体 DamageInfo 编号接入既有目标伤害观察、击杀提示、生涯和奖励。静态关系只提供候选来源；运行时仍结合当前目标、母来源及本人爆炸记录判断。

## 已接入的输入

- 当前弹体命中池的 `hit+0x0C` 是真实 DamageInfoType，原生指令 `0x13AD29B: 418b460c` 每次命中读取。它与 Health.record+0x40 的未知伤害段 token 是不同字段。
- 原生记录仍为 ABI 1、96 字节。在此前 producer 恒为零且 decoder 未使用的 offset36 保存具体编号，只有新增 flag512 时才有效；旧记录继续按原规则解析。
- 原本来源资源未通过筛选时，仅真实直接弹体、本人的完整归属、当前活体敌人及已审核伤害编号可以进入补充通道。flag1024 标记仅供归属，命中数为0；不靠这类记录增加命中绶带。
- 静态目录包含174个已知母来源、451个有类型节点；原生补充通道使用其中208个伤害编号。原始文件 SHA 与固定构建核对，默认构建只读已审核目录。

## 归属规则

1. 当前真实资源来源优先；编号能唯一定位已知母来源时可补充来源。
2. 共享编号结合该目标仍有效的母来源，或0.8秒内、有本人归属且覆盖目标位置的已知爆炸来源推测。位置只对当前已有变化的目标按需读取，不扫描全场。
3. 初次伤害就是破片时，也可读取该目标位置并关联本次爆炸。公开爆炸事件没有逐受害目标的原始爆炸伤害编号，因此纯爆炸死亡仅在已核验 kind4 时采用位置／来源近似；不据此抢占火焰、毒气或流血死亡。
4. 明确出现另一段未知伤害后仍截断，不跨过未知B/C回找旧武器。没有候选上下文的共享破片保留未知。

缓存最多64次近期本人爆炸。沿用10Hz观察、每轮最多8个来源增强目标；来源读取硬限512次／32KiB。位置按每目标每次增强最多1次调用另计，每轮最多8次；真实 Runtime 每次位置查询至多12次有界读取。读取间隙、跨任务和身份变化清除旧上下文。显示开关仍只控制提示，后台统计继续。

生涯先按原始来源哈希精确抵扣重归属；若 Health 只留下玩家实体而原生未知来源是另一个哈希，只有已保存的重归属额度和该局来源总数超额同时存在时，才抵扣相应未知显示池。原始行和哈希保留，不减少其他已知武器，不跨局抵扣，也不因为有未知就直接删掉。

## 验证与局限

本机原生生成机器码、自有内存、真实游戏LuaJIT及构建入口用于验证，不访问运行中游戏。历史profile保持原字节；新增指令读取由原有完整代码副本的前后字节证明覆盖。

这不是完整逐次伤害日志。漏掉命中／爆炸、目标太快销毁、破片落在可关联爆炸范围以外、网络缺少模拟记录或其他MOD替换武器引用时，仍可能未知或误配。同一玩家短时间的多个爆炸可能存在竞争；该部分是按来源、时间和位置的合理近似。旧记录缺失的逐击身份不能倒填。
