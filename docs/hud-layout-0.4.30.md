# 0.4.30 原生 HUD 布局

用户于 2026-10-13 确认 `hud-common-right-edge-v6` 网页预览并要求打包进游戏。此规格覆盖旧版侧边偏移和零死亡文字规则。

- 右上区域：左侧累计绶带换行，成就在其下；右侧依次是击杀、账单、射击次数和 KD 的图标与数字。TAB 打开时，成就下显示有记录的四类命中累计。
- 侧边通知：命中、绶带、成就三行，共用右边缘；图案数量在右下，成就名称在图案下。无新增 2 秒后统一收纳。同类累加，不新增重复控件。
- 数字变化：即时显示准确数值，180ms 短促放大、提亮并恢复；新通知轻微滑入。仅动画期间使用应用时钟，静止时复用缓存和控件。
- 战争账单普通白色；真实扣费显示“内容 -金额币种”，同类支出在当前批次合并。切换币种只改变显示，不产生新扣费。
- 零死亡显示 `240/0`；历史 KD 例如 `［75.96↑］`，箭头在数字后。零死亡时以当前击杀数比较历史 KD，相等时无箭头。
- 原生父控件沿用任务区域，继承游戏 HUD 弧度、缩放和边缘偏移。额外微调默认 0；升级仅迁移旧默认 18，保留其它自选偏移。任务让位使用实际换行、名称及支出高度；本批保留最大高度，收纳后释放。

图稿使用 v18，20 项战果图案与 4 项独立统计图标。击杀及 KD 内的骷髅来自确认的游戏原生圆眼图案，KD 仍保留斜线和阵亡标识。新增 R08/R09 图案不代表状态事件已经完成接入。

测试入口：ESC → MODS → 战果与战争账单 → 运行界面预览测试 → 侧边与收纳一起显示 → 应用。演示 8 秒，使用独立战果和支出，真实账目保持不变。

已完成离线模型、实际游戏 LuaJIT、已安装 HUD+ 0.2.1 Reader/Widgets 合约及安装包验证。原生 IO 使用隔离测试数据；本版实际游戏画面、HUD 弧度变化和帧率仍需实机确认。普通虫洞拆除、侦察以及异常施加的真实事件接入不属于本次布局变更。
