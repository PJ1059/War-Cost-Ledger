# 0.4.55 近战来源提示

问题是原生近战击杀计数已经驱动绶带，来源提示却没有消费这项证据。普通枪托／肘击还可能走 Ability 而没有独立武器实体，因此仅补武器资源名称不能解决。

本版复用同一份现有统计快照的 MELEE（0xC7680A1B）增长，只给当前计杀批次附近战额度，不增加原生读取。目标当前 owned Health 死亡记录 life2／kind6 与该额度同时存在时，消耗一次额度；若来源仍未知，显示“近战”，来源哈希保持为空。

已知具体武器继续优先，并同样消耗额度。kind6 还包含能力伤害，因此没有原生近战增长时不改名；普通射击也不会仅因同批有近战增长被改名。批次和目标超过原有0.75秒配对窗口、断读、换玩家、计数下降、切任务或切换提示开关时，不复用旧额度。首次读数和断读恢复只设基线。

该修正只补提示机制名称，不猜当前手持武器，不生成虚构武器资源，不额外增加绶带、计杀或费用，也不倒填旧武器记录。已知 CQC 武器通过原有来源路径显示武器名。新画面仍待实战确认。
